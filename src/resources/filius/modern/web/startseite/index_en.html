In the network

How the page gets to you

1

Resolve the address

If you typed a name, your computer first asks the DNS server for the IPv4 address.

2

Connect

The browser opens a TCP connection to the web server, on port 80.

3

Request the page

With GET / it asks for the start page. The server sends back index.html.

4

Load the pictures

For the logo the browser sends a second request: GET /rbz-logo.png.

Tip: Right-click your computer and choose Show data exchange. There you see each of these messages.

Join in

Try it yourself

  1. Install the Text editor on the web server.
  2. Use it to open the file webserver/index.html and change the heading, for example.
  3. Save the file and reload the page in the browser.
  4. Use the File explorer to put your own pictures on the server.

Willkommen

Herzlich willkommen am RBZ Wirtschaft . Kiel

Hallo! Diese Seite kommt von einem Webserver in deinem Filius-Netzwerk. Dein Browser hat sie gerade über HTTP abgerufen, genau wie eine echte Website im Internet.

Auf dem Server liegt sie als Datei index.html im Ordner webserver. Das Logo ist eine eigene Datei: rbz-logo.png.

Abgerufen von diesem Webserver

Im Netzwerk

So kommt die Seite zu dir

1

Adresse auflösen

Hast du einen Namen eingegeben, fragt dein Rechner zuerst den DNS-Server nach der IPv4-Adresse.

2

Verbindung aufbauen

Der Browser baut eine TCP-Verbindung zum Webserver auf, an Port 80.

3

Seite anfordern

Mit GET / fragt er nach der Startseite. Der Server schickt index.html zurück.

4

Bilder nachladen

Für das Logo stellt der Browser eine zweite Anfrage: GET /rbz-logo.png.

Tipp: Klicke mit der rechten Maustaste auf deinen Rechner und wähle Datenaustausch anzeigen. Dort siehst du jede dieser Nachrichten.

Mitmachen

Selbst ausprobieren

  1. Installiere auf dem Webserver den Text-Editor.
  2. Öffne damit die Datei webserver/index.html und ändere zum Beispiel die Überschrift.
  3. Speichere die Datei und lade die Seite im Browser neu.
  4. Eigene Bilder bringst du mit dem Datei-Explorer auf den Server.

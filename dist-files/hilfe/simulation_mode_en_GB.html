SIMULATION 

Simulation Mode

Now your network is running: you use the devices and watch how the data flows.

Using PCs and laptops

Click a PC or laptop to open its desktop. With Software Installation at the top left you install and remove programs. You can drag the border of the window to make it larger or maximize it with the button at the top right.

Every program carries a tag that shows its role in the network:

 Server 

offers a service to other devices, e.g. web pages or mailboxes.

 Client 

uses the service of a server, e.g. it fetches web pages.

 Peer-to-peer 

is client and server at once.

 Tool 

is neither client nor server, e.g. for editing files or testing the network.

Available programs with their tags

Double-click an icon to open the program. Whether its window is open or closed does not change its work. This matters especially for server programs.

Your own web pages

The Waterwolf web browser shows pages like a current browser: HTML5, CSS (e.g. flexbox, grid, variables, animations) and JavaScript (e.g. events, DOM, fetch, canvas, localStorage).

Put the files into the webserver folder of a PC running a web server: with the text editor (colours for HTML, CSS and JavaScript, line numbers, find with Ctrl+F, save with Ctrl+S) or by importing them in the file explorer. Every file the page loads (stylesheet, script, image) is a request of its own in the simulated network.

Tip: Open the data exchange of the laptop with the browser and reload the page: you see every single file as an HTTP request.

Encryption with HTTPS

In the window of the web server you switch on HTTPS at port 443 under Encryption (HTTPS) and, if you like, switch off HTTP at port 80. Certificate for holds the names and addresses the certificate is valid for, separated by commas; if it is empty, the certificate is valid for no server. The Filius Certificate Authority signs it; with Self-signed the signature is missing and browsers warn you.

In the web browser a lock in front of the address shows whether the page came encrypted (green), with a certificate the browser does not trust (red) or unencrypted (grey). A click shows the certificate. In the data exchange the messages are called TLS; sender and receiver also see the decrypted content there, all other devices only a jumble of characters.

VPN: home office

The programs VPN server and VPN client build an encrypted tunnel through the internet. In the VPN server you add users with passwords and start it; it waits at UDP port 1194. VPN addresses holds the network for the addresses in the tunnel (10.8.0.0), Network in the tunnel the network the clients can reach. Empty means: the network of the VPN server.

In the VPN client you enter the IPv4 address of the VPN server, user and password and click Connect. After that all packets for the network in the tunnel go encrypted to the VPN server, which sends them on with its own address. ipconfig shows the VPN adapter; in the data exchange the packets are called VPN. Stopping the simulation disconnects.

Viewing the IP configuration

The icon at the bottom right of the desktop bar shows the IP configuration of the device. A second click on the icon or a click on the desktop closes it again.

Watching the data exchange

When a packet travels through a cable, the cable fills with blue from the sender and then empties towards the receiver – the blue flows along with the packet. On a Wi-Fi link, radio waves go out from the sender and a signal point lights up at the receiver as soon as the packet has arrived.

A packet flows from the PC to the switch.

The Speed slider at the top slows down or speeds up the data exchange.

All data a device sends and receives is shown by Show data exchange in its context menu (right mouse button).

In the table each message takes one or more rows. The colours show which layer the data belongs to. Click a row to see all layers of this message below.

TCP/IP or OSI model

At the top right of the data exchange window you choose the layer model. It starts with the TCP/IP model and its four layers.

The OSI model shows all seven layers with their numbers, and next to them the TCP/IP layer they belong to. Filius has no data of its own for layers 1, 5 and 6; an explanation is shown instead.

A web page request in the OSI model

Tip: Compare both models for the same message: which OSI layers are part of the TCP/IP application layer?

Firewall of the router

Install a web browser on a connected laptop and enter an IPv4 address of the router in the address bar. On that page you switch the firewall on and off, configure it and see its log.

Viewing the switch table

A switch remembers through which port it reaches which MAC address (Source Address Table, SAT). Click the switch to see this table.
